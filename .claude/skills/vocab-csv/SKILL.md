# Vocab CSV

Turn the words **highlighted in yellow** in an exercise (screenshot of the passage and questions) into a CSV with the same structure as the sets in `output/<set name>/<set name>.csv` (generated by `script.py` from `base-vocab.json`).

The `vi` and `note` columns are written **in Vietnamese**, because the learners are Vietnamese.

## Output format (must match the existing sets)

- **UTF-8 with BOM** (`utf-8-sig`), **no header row**, comma separated, minimal quoting (QUOTE_MINIMAL).
- 7 columns, in this order: `en, ipa, pos, vi, formula, colloc, note`
- Line breaks in `note` become `<br>` (new paragraph = `<br><br>`).

| Column | Content |
|---|---|
| `en` | Base form (lemma): `pays off` → `pay off`, `falling` → `fall`, `supers` → `super`. Keep the passage form if it is an adjective with its own meaning (`uncapped`, `adapted`). |
| `ipa` | **British (RP)** IPA wrapped in `/.../`, e.g. `crop /krɒp/`, `narrow /ˈnærəʊ/`, `particular /pəˈtɪkjələ/` (non-rhotic, use /əʊ/ and /ɒ/), consistent with the project's `ipa.json`. Look up `ipa.json` first (key `word\|pos` or `word`); otherwise write it yourself. Any pronunciation mentioned in `note` is British too. |
| `pos` | Short tag as in the existing sets: `n`, `v`, `adj`, `adv`, `prep`, `phr v`, `idiom`, `prep phrase`, `determiner`. Use the part of speech **as used in the passage**. |
| `vi` | Vietnamese meaning (see the meaning rules). |
| `formula` | Grammar pattern if any: `pay off`, `catch on (with sb)`, `stash sth (away)`. Empty if none. |
| `colloc` | 2–4 common collocations, separated by `, `. |
| `note` | Explanation and examples (see the note rules). |

## Meaning rules (`vi`)

1. If the meaning in the passage **matches** the usual meaning, write the usual meaning, e.g. `"cổ đại, cổ xưa"`.
2. If the meaning in the passage **differs** from the usual one (technical or rare sense, phrasal verb with several senses…), use
   `"{meaning in the passage}, {other common meanings...}"`
   so the passage meaning **always comes first**. Example, `comb` in a beekeeping passage: `"sáp tổ ong (honeycomb), cái lược, chải (tóc)"`.

## Note rules

Write in Vietnamese, in the same voice as the existing sets ("Ví dụ khi bạn nói là: ... - ..."). Each note contains:

1. A short definition: `word (pos): ...`
2. **The example from the exercise**: quote the sentence or clause containing the word, with a translation. Start it with `Trong bài:`.
3. If the passage meaning differs from the usual one: explain the usual meanings and **add an example for each** (numbered `1.`, `2.`…), each with an English sentence and its translation.
4. If it matches the usual meaning: still add 1–2 examples that are not from the passage.
5. Optional: pronunciation tips, word family, memory aids, usage in academic Writing/Speaking.

## Workflow

1. Read every image carefully and list **all** words/phrases highlighted in yellow (in both the passage and the questions). Ignore words that are not highlighted.
2. Merge duplicates (same lemma and same pos, e.g. `supers` appearing twice → one row).
3. For each word, determine the meaning in context, compare it with the usual meaning and apply the meaning rules.
4. Write the data to a JSON file in the scratchpad (array of objects with all 7 keys; use `\n` for line breaks in `note`).
5. Name the set after the passage, in title case like the sets in `base-vocab.json` (e.g. `Migratory Beekeeping`). The name must not contain `<>:"/\|?*`.
6. Run the script to create the CSV; each set lives in its own folder:
   ```
   python .claude/skills/vocab-csv/scripts/build_csv.py <input.json> "output/<Set name>/<Set name>.csv"
   ```
   Example: `output/Migratory Beekeeping/Migratory Beekeeping.csv`. The script creates the folder, fills empty `ipa` cells from `ipa.json`, normalises `/.../`, turns `\n` into `<br>`, drops duplicate rows and reports words that still lack IPA (add British IPA to the JSON and run again).
7. Report to the user: the set folder path, the word count, the word list, and which words use the "passage meaning, common meanings" form.
